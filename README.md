# د. فاطمة أحمد إبراهيم المرغني خطاب - بورتفوليو صيدلي احترافي

منصة طبية شخصية متكاملة ومصممة بأعلى معايير الجودة (Apple-level Design) بواسطة طالبة الصيدلة فاطمة أحمد الخطاب (كلية الصيدلة 2026).

## 🚀 التثبيت والتشغيل المحلي
1. قم بفك ضغط ملف المشروع أو تحميله إلى حاسوبك.
2. افتح مجلد المشروع باستخدام برنامج **VS Code**.
3. قم بتشغيل خادم التطوير المحلي (Live Server) للاطلاع على الموقع.

## 🛠️ التخصيص
- يمكنك تعديل النصوص الشخصية في ملفات الـ HTML.
- ملفات التصميم موجودة في `/assets/css/` لتعديل الألوان والخطوط بكل سهولة.

## 📦 النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub.
2. ارفع جميع ملفات المشروع إلى الفرع الرئيسي (`main`).
3. انتقل إلى إعدادات المستودع (Settings) ثم **Pages**.
4. حدد مصدر النشر (Build and deployment) من فرع `main` ثم مجلد `/(root)` واحفظ التغييرات.
5. سيكون موقعك متاحاً خلال دقائق برابط GitHub Pages الخاص بك.
